- **작성일:** 2026-11-24
- **작성자:** Antigravity (영상·콘텐츠 R&D)

> **정직한 구분:** 아래 전략은 네이버 블로그(DIA+/스마트블록)·구글 검색 SEO의 일반 원리와 공정위 「추천·보증 심사지침」, 그리고 본 저장소의 `FIX-001` 진실성 규칙을 바탕으로 설계했습니다. 실제 블로그 방문자 수·클릭률 변화는 자비스 자동발행 적용 후 2~4주 실측 데이터로 검증합니다.

## 1. 기존 방식의 한계 (왜 유입과 전환이 안 나오는가)

1. **상품명 복붙 제목:** 검색자는 `"오엠티 접이식 휴대용 도마 물빠짐 바구니 대용량 7L"`가 아니라 `"좁은 싱크대 물빠짐 채반"`, `"캠핑 접이식 도마 추천"`, `"사무실 발난로 전기세"`처럼 **문제 상황·용도**로 검색합니다.
2. **5줄 링크 투척 = 네이버 저품질 위험:** 정보량·체류시간 없이 외부 제휴 링크만 던지는 글은 검색 노출에서 배제되기 쉽습니다.
3. **체험 사칭 불가 제약:** 직접 써 보지 않은 상품에 "내돈내산·써 보니"를 쓰면 법적·계정 정지 리스크가 큽니다. 대신 **「객관적 스펙 정리 · 사용 시나리오 · 구매 전 체크리스트 · 비교 가이드」** 포맷으로 정보 밀도를 높여야 합니다.
4. **릴스 ↔ 블로그 단절:** 20초 릴스(흥미·발견)와 블로그(검색·비교·확신)가 따로 놀아 유입 시너지가 없습니다.

## 2. 블로그 유입량을 늘리는 6가지 구체적 방안

| # | 방안 | 구체적 실행 방법 | 기대 효과 |
|---|---|---|---|
| **1** | **문제 해결형 롱테일 제목 공식** | `[광고] {상황/고민 키워드} {카테고리} — {제품명} 스펙·구매 전 체크 ({가격})` (35~45자) | 대형 키워드 경쟁을 피해 구매 의도가 높은 세부 검색어(스마트블록) 공략 |
| **2** | **7단 리서치형 구매 가이드 구조** | 대가성 고지 → 3줄 요약 → 스펙 표 → 핵심 포인트 3개 → 추천/주의 대상 → FAQ 3개 → CTA + 연관 상품 | 체험 사칭 없이 체류시간 1.5~3분 확보, "광고지만 도움 되는 글" 인식 |
| **3** | **내부 링크 클러스터링 (`products.json` 연동)** | 글 하단에 같은 카테고리의 기존 추천템 2~3개를 자동 연결 ("함께 비교해 볼 만한 살림템") | 페이지뷰·체류시간 증가, 추천 페이지(`docs/`) 트래픽 순환 |
| **4** | **제휴 링크 개수·위치 절제** | 본문 중간(스펙 표 직후) 1회 + 하단 1회 = **최대 2회만** 배치 (도배 금지) | 네이버 스팸/저품질 필터 회피 + 가장 확신이 생긴 지점에 클릭 유도 |
| **5** | **릴스 ↔ 블로그 크로스 링크** | ① 릴스 대본의 핵심 소구 3개를 블로그 소제목 3개로 그대로 확장 ② 블로그 상단에 "20초 요약 릴스 핵심" 배치 ③ 릴스 캡션/프로필 링크에서 블로그·추천템 연결 | 1개 상품 리서치로 인스타·쇼츠·검색 3채널 동시 수확 |
| **6** | **발행 직전 진실성 하드 게이트 (`FIX-001`)** | 체험 사칭("내돈내산/써 보니/친구 집"), 근거 없는 "1위/최저가/별점", 가격 불일치, 대가성 문구 누락 시 **발행 자동 차단** | 계정·제휴 정지 리스크 원천 차단, 클릭 후 가격 불일치 이탈 방지 |

## 3. 자비스 자동발행 연동 구조 (표준 파이프라인)

```text
[자비스 상품 JSON + 확인된 사실 3개]
        │
        ▼
generate_blog_post.py  ◄── docs/products.json (같은 카테고리 연관 상품 2~3개 자동 매칭)
        │
        ├─ 1) FIX-001 진실성 검사 (위반 시 exit 1 → 발행 중단)
        ├─ 2) 7단 SEO 마크다운 (blog_post.md) 생성
        ├─ 3) 네이버 블로그 붙여넣기용 HTML (blog_post.html) 생성
        └─ 4) 제목·태그·메타데이터 JSON (blog_meta.json) 생성
        │
        ▼
[자비스 블로그 발행기 자동 업로드 / 또는 대표 최종 확인 후 발행]
```

### 실행 예시
```bash
python jarvis-skills/skills/jarvis-publish/scripts/generate_blog_post.py \
  --product-no 21 \
  --problem "좁은 싱크대·캠핑장에서 도마와 채반을 따로 챙기기 번거로울 때" \
  --facts "다 쓰면 납작하게 접히는 접이식 구조|도마·채반·물빠짐 바구니 일체형|대용량 7L 구성(판매자 상품명 표기)" \
  --out-dir /tmp/blog-21
```

## 4. 네이버 블로그 저품질 회피 운영 체크리스트

- [ ] **원본 상품 사진 + 자체 제작 릴스 캡처 컷**만 사용 (타인 블로그 후기 사진 크롤링 금지 — `FIX-003`)
- [ ] **같은 날 동일 키워드·복붙 문장 반복 금지** (상품별 확인된 사실 3개 + 고민 키워드 필수 입력)
- [ ] **정보성 글(찰스 지식영상 생활과학 편)과 제품 글 비율 유지** (권장: 제품 글 3~4편당 생활과학/정보 글 1편 이상 섞어 채널 지수 방어)
- [ ] **가격은 항상 `MM/DD 기준 오늘 확인가` 표기** ("최저가" 단정 금지)
