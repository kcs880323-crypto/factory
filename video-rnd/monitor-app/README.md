# 자비스 영상일꾼 · 퀄리티 R&D 모니터 앱

바탕화면에 바로가기를 두고 블로그 발행기처럼 한 번 클릭해 열어 쓰는 로컬 데스크톱 모니터링 앱입니다.  
추가 패키지 설치 없이 **Python 3 표준 라이브러리**만으로 실행되며, 크롬/엣지 독립 앱 창(`--app`)으로 열립니다.

## 제공하는 기능 (4개 탭)
1. **개선 조치 이력:** 몇 월 며칠에 어떤 부분(제품 릴스 · 추천 페이지 · 품질 가드 · A/B 실험)을 개선 조치했는지 날짜 최신순 요약 + 상태 필터
2. **R&D 실험 현황:** `video-rnd/EXPERIMENT_LOG.md`의 R 라인(`FIX-001`, `EXP-005~007`) · K 라인(`EXP-001~004`) 실시간 조회
3. **영상일꾼 · 추천템 점검:** 로컬 `영상일꾼_DESKTOP-4CMADIK` 최근 렌더 MP4 목록(읽기 전용, 키/쿠키 미접근) + `docs/products.json` 이미지 누락/중복 상품 자동 무결성 검사
4. **회의 보드 · 결정 로그:** `SYNC_BOARD.md` 현황판 및 결정 로그(`DEC-000`~) 실시간 조회

## 바탕화면 앱으로 두는 법 (Windows)
1. `factory` 폴더에서 `git pull origin claude/jarvis-skills-delivery-75yvpx`
2. `video-rnd\monitor-app\자비스_영상일꾼_모니터.bat` 파일 우클릭 → **보내기 → 바탕 화면(바로 가기 만들기)**
3. 바탕화면 아이콘 더블클릭으로 실행 (`http://127.0.0.1:8787` 앱 창이 자동으로 열립니다)
