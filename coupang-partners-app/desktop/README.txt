파트너스 매니저 — PC 설치판 (Windows)
========================================

쿠팡 파트너스 API와 네이버 API(API HUB 쇼핑인사이트, 쇼핑 검색)를 PC에서 쓰기 위한 설치판이에요.
앱 화면과 작은 중계 서버가 이 PC 안에서만(http://127.0.0.1:8790) 돌아가요. 다른 기기에서는 접속할 수 없어요.

설치
----
1. 이 압축 파일을 마우스 오른쪽 → "압축 풀기"로 풀어요. (압축 파일 안에서 바로 실행하면 안 돼요)
2. 풀린 폴더의 install.bat 을 두 번 눌러요.
   - Node.js 18 이상이 필요해요. 없으면 다운로드 페이지가 열려요 (LTS 설치 후 다시 install.bat).
   - 관리자 권한은 필요 없어요. %LOCALAPPDATA%\PartnersManager\app 에 설치돼요.
3. 바탕화면의 "파트너스 매니저" 아이콘으로 실행해요. 주소창 없는 앱 창(Edge)이 열려요.
4. 설정 탭에서 쿠팡 파트너스 Access/Secret Key, 네이버 API HUB Client ID/Secret을 넣고 "연결 확인"을 눌러요.

알아 둘 것
----------
- 키와 링크 보관함은 이 앱 전용 브라우저 저장소(%LOCALAPPDATA%\PartnersManager\browser)에만 저장돼요.
  서버는 키를 저장하거나 기록하지 않고, 쿠팡·네이버로 전달만 해요. 쿠팡 요청 서명은 앱 화면에서 해요.
- 실행하면 작업 표시줄에 "Partners Manager server" 창이 최소화돼 있어요. 이 창을 닫으면 서버가 꺼져요.
  앱 창을 닫고 10분이 지나면 서버가 스스로 꺼져요.
- 업데이트: 새 압축 파일을 풀고 install.bat 을 다시 실행하면 돼요. 키·보관함은 그대로 남아요.
- 지우기: 설치 폴더(%LOCALAPPDATA%\PartnersManager\app)의 uninstall.bat. 키·보관함은 물어본 뒤에만 지워요.
- 백신·보안 프로그램이 install.bat(PowerShell)을 막으면: 이 폴더를 원하는 곳에 두고 start.bat 바로가기를
  직접 바탕화면에 만들어 써도 돼요.
- Claude 아티팩트 화면에 저장한 링크는 이 PC판으로 자동으로 옮겨지지 않아요.
- 쿠팡이 만든 공식 앱이 아니에요. 약관·정산 기준은 항상 쿠팡 파트너스 사이트가 우선이에요.
