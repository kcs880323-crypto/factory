# 자비스에게 붙여넣을 프롬프트 모음 (지식영상 제작)

순서대로 쓰세요: **A (준비) → B (재현 시험) → C (진짜 영상)**. 각 프롬프트 안의 `<…>`만 내 환경에 맞게 바꾸면 됩니다.

- `<매뉴얼>` = `MANUAL.md` 파일의 전체 경로 (키트를 푼 폴더, 또는 저장소의 `knowledge-videos/MANUAL.md`)
- 자비스에 **최신 jarvis-skills(스킬 33개)가 설치돼 있어야** 합니다 (`jarvis-knowledge-video` 스킬이 있어야 함). 옛 15개 판에는 없습니다.

## A. 준비 점검 (처음 한 번)

```text
역할: 지식영상 제작 환경을 점검하고 준비하는 담당
맥락: 앞으로 내가 "지식영상 생성"이라고 하면 찰스의 35~45초 한국어 지식 영상을 만들어야 합니다. 그 방법은 <매뉴얼> 파일에 있습니다. 먼저 이 컴퓨터가 준비됐는지 확인합니다. 영상은 아직 만들지 않습니다.
먼저 할 일: <매뉴얼>을 처음부터 끝까지 읽으세요. 이번에는 2장(준비)만 실행합니다.
작업 (순서대로):
1. 2-1의 도구를 실제로 실행해 버전을 확인하세요: node, python(안 되면 python3 또는 py -3), ffmpeg, ffprobe, claude. 기준에 못 미치는 것은 표시하세요.
2. 2-2의 파일 목록을 확인하세요: ~/.claude/skills/jarvis-knowledge-video 안의 SKILL.md, scripts 9개, assets/charles(포즈 PNG 4장과 charles.json), reference/charles의 JSON 2개. 하나라도 없으면 여기서 멈추고 "최신 jarvis-skills(스킬 33개)가 설치되지 않은 것 같다"고 알려 주세요.
3. 2-3: `claude plugin list`에 hyperframes@hyperframes 가 있는지 확인하세요. 없으면 설치하기 전에 나에게 먼저 묻고, 내가 허락하면 매뉴얼의 고정 버전(v0.8.197) 명령으로 설치하세요. plugin-cli.mjs의 경로를 찾아 알려 주세요.
4. 2-4: ~/.jarvis-knowledge-video 폴더가 있는지 확인하세요. 없으면 매뉴얼의 알림 표(내려받는 것, 설치 위치, 외부로 나가는 것, 라이선스)를 나에게 그대로 보여 주고 동의를 받은 뒤에만 setup_tts.py를 실행하세요. 끝나면 출력의 PY= 와 MODEL= 값을 알려 주세요.
5. 2-6의 변수(S, PY, MODEL, CLI)에 들어갈 실제 값을 표로 정리하세요.
제약:
- 내가 허락하기 전에는 아무것도 설치하거나 내려받지 마세요 (읽기와 확인만).
- 기존 파일을 덮어쓰거나 지우지 마세요. .env와 비밀키 파일은 열지 마세요.
- 텔레메트리를 켜지 말고(HYPERFRAMES_NO_TELEMETRY=1, DO_NOT_TRACK=1), 피드백 전송과 publish, auth login은 하지 마세요.
- 실행해 본 것만 "확인함"이라고 쓰고, 안 해 본 것은 "확인 안 함"이라고 쓰세요.
출력: 항목 | 결과(✅/❌/설치 안 함/확인 안 함) | 근거(실행한 명령과 핵심 출력 한 줄)의 표, 마지막에 내가 해야 할 일(동의, 재시작 등).
검증: 4개 도구와 스킬 파일과 플러그인과 음성 준비가 모두 ✅일 때만 "준비 완료"라고 하세요. 하나라도 아니면 원인과 다음 조치를 알려 주세요.
```

## B. 재현 시험 (같은 영상이 나오는지)

준비가 끝난 뒤, **내 주제로 만들기 전에** 이미 검증된 「꿀벌의 8자 춤」을 똑같이 만들어 보게 합니다. 여기서 막히면 진짜 영상도 막힙니다.

```text
역할: 지식영상 제작 방법이 이 컴퓨터에서 제대로 되는지 시험하는 담당
맥락: <매뉴얼>의 방법으로 만든 「꿀벌의 8자 춤」(43초)이 기준입니다. 같은 대본과 같은 화면 생성기로 이 컴퓨터에서 똑같이 만들어 보고, 매뉴얼 9장의 기준표와 비교하세요. 이 영상은 시험용이라 올리거나 전달하지 않아도 됩니다.
작업:
1. <매뉴얼>을 처음부터 끝까지 읽고, 준비(2장)가 끝났는지 확인하세요 (안 됐으면 멈추고 알려 주세요).
2. 새 작업 폴더 knowledge-videos/bee-test/ 를 만들고 examples/bee-waggle-dance/ 의 clauses.json 과 build_video.py 를 복사하세요 (영문 폴더 이름만 쓰세요).
3. 매뉴얼 4장의 단계 4~9를 순서대로 실행하세요 (대본 쓰기와 생성기 쓰기는 이미 있으니 건너뜁니다). 절마다 6번 합성해 고르는 4-1은 음성인식 모델이 이미 있을 때만 하고, 없으면 1번만 합성하세요.
4. 단계 7에서 snapshot 이미지를 직접 열어 눈으로 확인하세요 (오프닝, 어두운 벌집, 8자 춤, 각도 패널, 막대 두 개, 1973, 엔딩).
5. 매뉴얼 9장 표의 각 항목에 이 컴퓨터의 실제 값을 채워 비교하세요.
각 단계가 끝날 때마다 한 줄로 진행 상황을 알려 주세요 (오래 걸리는 렌더는 시작할 때 "몇 분 걸린다"고 알려 주세요).
제약: 매뉴얼의 고정값(목소리 5, 속도 1.2, natural, 오프닝·엔딩 문구)을 바꾸지 마세요. 기존 영상과 폴더를 덮어쓰지 마세요. 소리는 들을 수 없으니 "소리가 좋다"고 쓰지 마세요.
출력: 9장 형식의 비교표(항목 | 기준 | 이 컴퓨터 값 | 합격/불합격), 막힌 단계와 오류 메시지 전문, 스스로 고친 것.
검증: check 오류 0, verify_video.py 전부 PASS, 길이 41~45초일 때만 "재현 성공"이라고 하세요. 아니면 실패한 단계와 이유를 알려 주세요.
```

## C. 진짜 영상 만들기 ("지식영상 생성")

B가 성공한 뒤에 씁니다. 주제를 정하지 않으려면 "무작위"라고 쓰세요.

```text
지식영상 생성: <주제 또는 "무작위">

<매뉴얼>의 절차를 그대로 따라 영상 한 편을 만들어 줘. 매뉴얼 4장의 단계 1~10을 모두 하고, 건너뛰는 단계가 있으면 이유를 알려 줘.
요구:
- 주제는 knowledge-videos/ledger.json 에 없는 것 (이미 있는 주제: 꿀벌의 8자 춤, 문어의 심장은 세 개). "무작위"면 네가 골라서 먼저 한 줄로 알려 줘.
- 사실 확인은 웹 검색으로 하고 SOURCES.md 를 쓰되, 원문을 직접 읽지 못한 것은 "검색 요약으로만 확인"이라고 적어 줘. 확인 못 한 것은 빼거나 "~로 알려져 있다"로 써.
- 본편 대본은 공백·문장부호 제외 125~160자(145자 안팎 권장), 5줄, 숫자는 읽는 형태로. 대본을 쓰면 render 전에 글자 수와 함께 나에게 먼저 보여 줘 (내가 "좋아"라고 하면 진행).
- 목소리는 매뉴얼 5장의 고정값 그대로. 절마다 6번 합성해 고르는 것(4-1)은 음성인식 모델이 있으면 해 줘.
- 화면은 예시 build_video.py 를 복사해 이 주제의 장면으로 바꿔 써 (그대로 복사 금지). check 오류 0, snapshot 이미지를 직접 눈으로 보고 고친 뒤에 렌더해 줘. 어떤 시점을 봤고 무엇을 고쳤는지 알려 줘.
- 렌더 뒤 verify_video.py 전부 PASS, 렌더한 MP4에서 프레임도 직접 확인해 줘.
- 끝나면 publish.json, SOURCES.md, clauses.json, build_video.py 를 knowledge-videos/<slug>/ 에 두고 ledger.json 에 기록해 줘. MP4 는 저장소에 올리지 마.
- 영상 파일을 나에게 전달해 줘.
지켜 줘:
- 오프닝·엔딩 문구, 찰스 그림, 목소리 5·속도 1.2·natural 은 바꾸지 마. 오프닝 낭독문은 "찰스입니다." 그대로.
- 내가 요청하지 않았으면 유튜브·인스타그램에 올리지 마. (올려 달라고 하면 jarvis-publish 절차대로 올릴 내용을 먼저 보여 주고 확인받아.)
- 동의 없이 외부 서비스(HeyGen, 클라우드 음성 등)를 쓰지 마. 텔레메트리는 꺼 둔 채로.
- 소리는 들을 수 없으니 발음·억양을 "좋다"고 보고하지 말고, 측정한 것과 못 들은 것을 나눠서 보고해 줘.
- 각 단계가 끝날 때마다 한 줄로 진행 상황을 알려 줘.
보고 형식: 매뉴얼 10장.
```

## 자주 쓰는 한 줄 명령 (준비가 끝난 뒤)

| 하고 싶은 것 | 이렇게 말하세요 |
|---|---|
| 영상 한 편 | `지식영상 생성` (주제 없이) 또는 `지식영상 생성: 무지개` |
| 들어 본 뒤 목소리를 바꾸고 싶다 | `목소리를 바꿔 줘. 샘플을 만들어서 보내 줘` (번호·속도·톤을 바꿔 같은 문장의 샘플을 만든다. 내가 고르기 전에는 기본값을 바꾸지 않는다) |
| 일부만 고치기 | `방금 영상의 <절 번호>를 "<새 문장>"으로 바꿔서 음성부터 다시 만들어 줘` |
| 업로드 | `지식영상 유튜브·인스타 업로드` (올릴 내용을 먼저 보여 주고 확인받는다. 처음이면 jarvis-publish 연결부터) |
