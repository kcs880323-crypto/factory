# 플레이북: AI 브리핑

예: "오늘 브리핑 해줘", "매일 아침 8시에 일정이랑 중요한 메일 정리해서 알려줘"

## 언제 쓰나

하루 시작·마감 요약, 주간 정리 요청. 정기 실행 요청이면 예약 작업을 제안한다.

## 구성 (기본값, 하나씩 켜고 끌 수 있다)

1. 오늘 일정 (시간순, 이동·준비가 필요한 것 표시, 겹침 경고)
2. 답장이 필요한 메일 3~5개 (보낸 사람, 한 줄 요약, 기한)
3. 오늘 마감·할 일 (사용자가 알려 준 것만)
4. (원하면) 날씨·교통: 웹 검색으로 확인한 것만, 확인 시각 표시
5. 한 줄 제안: "오늘 오후 2~4시가 비어 있어요. 밀린 ○○를 넣을까요?"

## 순서

1. 연결된 캘린더·메일을 조회한다 (읽기, 자동).
2. 위 구성으로 10줄 안에 정리한다. 길면 중요한 순서로 자른다.
3. 제안은 **하나만** 한다.
4. 정기 브리핑을 원하면: 시각, 받는 방법(이 대화/알림), 내용 범위를 제안하고 **사용자 동의 후** 예약 작업을 만든다 (동의 전에는 만들지 않는다. 만든 뒤 목록과 끄는 방법을 알려 준다).

## 위험 단계

읽기(T0). 예약 작업 생성은 계속 실행되는 일이므로 확인한다.

## 보고 형식

```text
좋은 아침이에요. 오늘은 일정 3개, 답장 필요한 메일 2개예요.
09:30 팀 회의 (회의실 B) ...
...
제안: ...
```

## 후속 제안

- "내일부터 매일 아침 8시에 이렇게 받아 보실래요?"

## 지켜야 할 것

- 메일·일정 내용은 사용자 본인의 정보다. 다른 곳에 보내거나 저장하지 않는다.
- 브리핑에 민감한 내용(인증번호, 금융 정보)은 넣지 않는다.
